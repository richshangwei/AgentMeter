# Copilot P0 follow-up handoff — 2026-09-07

## Scope

This handoff covers only issue 03 criteria 2 and 3. It strengthens the sanitized replay contract; it does not claim access to a real GitHub account, organization, enterprise, token, or billing response.

## Changes

- Added `tests/fixtures/copilot/contexts-boundaries.json` with explicit endpoint and permission contracts for all three contexts.
  - Personal billing usage: fine-grained user `Plan:read` and `personal_account_owner` fixture role.
  - Business organization billing usage: organization `Administration:read` and `organization_administrator` fixture role.
  - Enterprise billing usage: enterprise `Enterprise billing:read` and an allowed billing-manager fixture role.
- The Copilot normalizer now emits required/observed scopes, fine-grained permissions, roles, missing values, contract status, and human-readable diagnostics. Organization/enterprise roles are treated as alternatives; one authorized role is sufficient.
- Added normalized `quota_boundaries` for AI Credits and legacy premium requests. Each retains its own unit, included allowance, used/remaining values, billing period, overage/extra-paid facts, and pool scope. The output explicitly marks `aggregation: never_sum_across_units`.
- Added regression tests for satisfied Personal/Enterprise contracts, missing Business permission and role diagnostics, individual allowance/overage, and enterprise shared-pool versus individual-limit separation.

## Primary documentation used for the mapping

- [GitHub REST billing usage](https://docs.github.com/en/rest/billing/usage): user AI-credit and premium-request reports require fine-grained `Plan` user permission (read); organization billing AI-credit reports require `Administration` organization permission (read).
- [GitHub Enterprise Cloud REST billing usage](https://docs.github.com/en/enterprise-cloud@latest/rest/billing/usage): enterprise AI-credit and premium-request reports require `Enterprise billing` enterprise permission (read), with administrator/billing-manager/organization-owner access paths.
- [GitHub usage-based billing for organizations and enterprises](https://docs.github.com/en/copilot/concepts/billing/organizations-and-enterprises/usage-based-billing): included AI Credits are pooled at the billing entity level, while user-level budgets can independently stop a user before the shared pool is exhausted.
- [GitHub legacy premium requests](https://docs.github.com/en/copilot/reference/copilot-billing/request-based-billing-legacy/copilot-requests): legacy premium-request allowances and paid additional requests are a separate, request-based measure.
