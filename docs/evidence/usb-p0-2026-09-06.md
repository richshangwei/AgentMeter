# Ticket 07 USB loopback P0 evidence

The fixture-driven experiment is implemented by `agentmeter-usb-p0`. It models an explicit ADB serial, separate host/device ports, loopback-only binding, no-rebind conflict detection, authenticated reachability, browser-launch separation, reconnect events, and owned teardown.

The healthy fixture proves the expected supported shape. The browser-only fixture remains offline until an authenticated health response succeeds, and the conflict fixture fails closed for a LAN bind and an occupied mapping.

Real ADB/device validation is unavailable in this environment: no authorized Android device serial was provided. Ticket 07 therefore remains `needs-info` until an operator runs the binary against a real selected serial and records `adb devices`, `adb reverse --list`, the endpoint probe, and teardown output.
